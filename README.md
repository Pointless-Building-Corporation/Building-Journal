
Building Journal
=======

This is the Building Journal mod.

**Current progress** -> Around 75% feature complete.

This mod is built for NeoForge for MC Version 1.20.1.

The original purpose of this mod is to integrate with the Pointless Building Modpack, which is currently WIP. However, this mod is designed to work
out-of-the-box as a standalone mod as well.


**Assets used** (that is not my own):
- Sound effects from "50 RPG Sound Effects" by Kenney.nl (https://opengameart.org/content/50-rpg-sound-effects)
